🚖 RideOptimiser – Smart Ride Booking System
📌 Overview

RideOptimiser is a GUI-based ride booking simulation system built using Python.
It uses advanced pathfinding algorithms like A* and Dijkstra to calculate optimal routes between cities in India.

🎯 Features
🚀 Fastest route using A* Algorithm
🌿 Eco-friendly routing
🚧 Avoid city/toll feature
📍 Real-time map visualization
🚗 Driver allocation system
📊 Dynamic surge pricing
⏱️ ETA & Fare calculation
📜 Ride history tracking
⭐ Driver rating system
🧠 Algorithms Used
A* Algorithm → for fastest route (time-based)
Dijkstra Algorithm → for shortest distance
Priority Queue (Heap) for optimization
🛠️ Technologies Used
Python
Tkinter (GUI)
Data Structures (Graph, Heap, Queue)
JSON (for storing ride history)
📂 Project Structure
app.py          # Main application
graph.py        # Graph data structure
routing.py      # Pathfinding algorithms
driver.py       # Driver management
booking.py      # Booking & queue system
ui.py           # UI components
ride_history.json  # Stored ride data
▶️ How to Run
Install Python (3.x)
Run the project:
python app.py
📸 Output
Interactive map of Indian cities
Route visualization
Driver movement simulation
